# moixhka — portfolio of Moisés Camargo Cano

Single-page portfolio for composer / violinist Moi Camargo.
Layered "sheets of paper" parallax hero (pure CSS + a `requestAnimationFrame` loop), papel picado background, real embeds from Spotify, YouTube and SoundCloud.

- `index.html` — the whole site, self-contained
- `moi.png` — transparent line-art portrait (cut out from Moi's public avatar)

No build step. Deploy as a static site.
